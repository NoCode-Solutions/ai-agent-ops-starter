# 02 止まって確認する条件を足す

**合図：**指示していないのに勝手に進んだ。確認してほしかった場面で確認されなかった。

その場面を1行として足します。起きた直後に貼るのが一番効きます。時間が経つと、どこで止まってほしかったのかが曖昧になります。

## 貼るもの

```
いま勝手に進んでしまった箇所を、CLAUDE.md の「止まって確認する条件」に
1行として追加してください。どういう場面で、なぜ止まるべきかを書きます。
既存の行と重複しないか確認してから足してください。
```

## 確かめる

- 追加された1行が、**場面の記述になっているか。**「慎重に進める」のような心構えは条件になりません
- 既存の行と重複していないか。同じことが2通りの言い方で並ぶと、どちらも守られなくなります

止まる条件が10行を超えたら、書きすぎている可能性があります。毎回止まるようになると、止まること自体が形骸化します。
