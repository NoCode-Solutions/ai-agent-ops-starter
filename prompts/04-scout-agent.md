# 04 探索の担当を分ける

**合図：**調べ物をさせると、本題の指示が押し流される。

探索は中間の出力が大量に出ます。それを本体に読ませると、最初に出した指示が奥へ押しやられます。調べる係を別に立てて、結果だけを受け取る形にします。

## 貼るもの

```
このリポジトリに、探索専用のサブエージェントを作ってください。

- 置き場所は .claude/agents/scout.md
- 役割は「多数のファイルを走査して該当箇所を一覧にする」ことだけ
- 読み取り系のツールだけを許可し、書き込み・編集・削除は許可しない
- 判断も評価も編集もさせない。事実を集めて返すところまで
- 返し方の形式を指定する（結果の一覧／走査した範囲／該当なしだったもの）
- 「勝手に件数を絞らない。多い場合は全件数を書いてから絞った基準を書く」を明記する

作ったら、どういうときに呼ぶか、どういうときに呼ばないかを3行で説明してください。
```

## 確かめる

- 書き込み系のツールが許可されていないか
- 「勝手に絞らない」と「該当なしも報告する」が本文に入っているか

この2行は、実際に困ったので足した項目です。件数が多いときに黙って上位だけ返されると、呼んだ側は全件を見た結果だと思って判断します。**無言の打ち切りは、間違った答えより厄介です。**

## 呼ばない場面

数回のツール呼び出しで終わる調べ物には使わないでください。別のエージェントを立てると、そちらに前提を渡し直す手間がかかります。委譲するのは、中間出力が大量に出る作業だけです。

弊社が使っている実物は [`../examples/agents/scout.md`](../examples/agents/scout.md) にあります。
