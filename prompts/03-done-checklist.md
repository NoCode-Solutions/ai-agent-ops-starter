# 03 完了前のチェックリストを足す

**合図：**「できました」が当てにならない。あとで開いたら出来ていなかった。

AIは、できなかったときも正常終了します。人間なら失敗と呼ぶ状態が、機械からは成功に見えます。完了の宣言に証拠を要求する項目を、ルールのファイルに入れておきます。

## 貼るもの

```
CLAUDE.md の「完了前のチェックリスト」に、次の項目を追加してください。

- 動くこと・存在することの証拠を出したか（コマンド出力・HTTPステータス・画面）
- 成果物を自分で開いて確かめたか
- 変更前後で同じ入力を流して結果を比べたか（既存の仕組みに触れたとき）

追加したら、今後この一覧を完了前に必ず通すことを CLAUDE.md に明記してください。
```

## 確かめる

次に完了報告を受けたとき、証拠が添えられているか。添えられていなければ、その場で「どうやって確認した？」と聞いてください。1〜2回聞くと、聞かなくても出てくるようになります。

## 自動化に載せるときの注意

決まった時刻に処理を走らせる仕組みでは、終了コードを成否の根拠にしないでください。エージェントは「この方法が使えないので代わりの方法でいいですか」と質問して正常終了します。処理が0件でも終了コードは0です。

冪等の判定は完了マーカーではなく、**保存先の実状態**で行ってください。マーカーは嘘をつきますが、実状態は嘘をつきません。実例は [`../examples/memory/feedback_exit-code-is-not-success.md`](../examples/memory/feedback_exit-code-is-not-success.md) にあります。

一覧の全文は [`../plugins/ai-agent-ops/reference/before-done.md`](../plugins/ai-agent-ops/reference/before-done.md) にあります。
