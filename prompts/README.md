# プロンプト集（予備）

**通常はプラグインを入れてください。**[トップのREADME](../README.md) の2行で、共通のファイルはそのまま入り、スキルが質問しながら残りを作ります。

ここは、プラグインが使えないときの手作業の道です。Claude Codeのバージョンが古い、gitに繋がらない、別のエージェントを使っている、といった場合はこちらを使ってください。**貼れば同じものができます。**ただし生成のたびに文面は揺れるので、`scout` の「勝手に件数を絞らない」のような効く1行が落ちていないか、貼ったあとに確かめてください。

**最初に貼るのは [`01-foundation.md`](01-foundation.md) だけです。**残りは、下の合図が出てから貼ってください。使ってもいない仕組みを先に入れると、使われないまま残ります。

| いつ貼るか | プロンプト |
|---|---|
| 最初に1回 | [`01-foundation.md`](01-foundation.md) 土台をつくる |
| 指示していないのに勝手に進んだ | [`02-stop-condition.md`](02-stop-condition.md) 止まって確認する条件を足す |
| 「できました」が当てにならない | [`03-done-checklist.md`](03-done-checklist.md) 完了前のチェックリストを足す |
| 調べ物をさせると本題が押し流される | [`04-scout-agent.md`](04-scout-agent.md) 探索の担当を分ける |
| ルールに書いたのに危ない操作をやろうとする | [`05-block-outbound-hook.md`](05-block-outbound-hook.md) 実行の直前に機械で止める |
| 同じ手順を3回以上説明している | [`06-skill.md`](06-skill.md) 手順をファイルにする |
| 毎朝、状況を説明し直している | [`07-inject-now-hook.md`](07-inject-now-hook.md) 現在地を起動時に読ませる |

Claude Code を想定していますが、考え方は他のエージェントでも同じです。パスの表記だけ読み替えてください。

## 貼ったあとにやること

どのプロンプトも、**出来上がったものを自分で開いて確かめてください。**「作成しました」という報告は、作成された証拠ではありません。フックとスキルは特に、登録の書式と実行権限で無言の失敗をします。各ファイルの末尾に確認項目を書いてあります。
