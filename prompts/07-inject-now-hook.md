# 07 現在地を起動時に読ませる

**合図：**毎朝、いま何をしているかを説明し直している。

`memory/NOW.md` を作ってあっても、読ませ忘れれば意味がありません。起動時に自動で読み込ませます。

## 貼るもの

```
セッションの開始時に memory/NOW.md をコンテキストへ自動で読み込ませる
フックを作ってください。

- 置き場所は .claude/hooks/inject-now.sh
- SessionStart で発火させ、.claude/settings.json に絶対パスで登録する
- 100行を超えていたら打ち切り、「整理してください」という警告を末尾に足す
- 実行権限を付け、実際に1回動かして出力を見せてください
```

## 確かめる

新しいセッションを開いて、**説明していないのに現在の状況を把握しているか。**把握していなければ、登録のパスか実行権限を疑ってください。

## 上限を決める理由

行数の上限は、これを毎回読み込ませるためのものです。決めておかないと、終わった案件の記録が積み上がって、現在地のファイルがいつのまにか履歴になります。履歴は `memory/project_*.md` 側に移します。

打ち切りの警告を入れてあるのは、上限を超えたことに気づく仕組みがないと、上限が守られないからです。

動く実装は [`../plugins/ai-agent-ops/hooks/inject-now.sh`](../plugins/ai-agent-ops/hooks/inject-now.sh) にあります。
