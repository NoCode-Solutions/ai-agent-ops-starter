自動化スクリプトでAI経由の処理を呼ぶとき、**終了コード0を「やった」の証拠にしない**。
副作用が起きたかどうかは、実際の保存先に問い合わせて確かめる。

**Why:** 2026-08-03に週次処理が欠落した事故の主因。処理が成功したら完了マーカーを書く、
という書き方をしていた。AIは「この接続が使えないので別の方法で代替していいですか？」と
質問して正常終了した。1行も作られていないのにマーカーが書かれ、リトライも封じられた。

**How to apply:**
- 冪等の判定はマーカーではなく保存先の実状態で行う。マーカーは嘘をつくが、
  実状態は嘘をつかない。
- 副作用のある処理は、可能ならAIを介さず決定的なコードにする。
- どうしてもAI経由にするなら、出力に「作成したID」を出させ、それを検索してから
  成功とみなす。
