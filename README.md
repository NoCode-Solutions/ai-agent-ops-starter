# ai-agent-ops-starter

AIエージェントを毎日の業務に載せるための、**貼るだけのプロンプト集**です。

AIに仕事を頼むたびに、会社のこと、担当のこと、やってはいけないことを説明し直していませんか。説明した内容は、そのウィンドウを閉じた時点で消えます。翌日はまた一からです。

この繰り返しから抜けるための土台は、手で書く必要がありません。**エージェント自身に作らせます。**

## まずこれを貼る

[`prompts/01-foundation.md`](prompts/01-foundation.md) を、作業したいリポジトリで開いたエージェントにそのまま貼ってください。5問の質問に答えると、ルールのファイルと記憶の置き場ができます。所要は10分ほどです。

残りのプロンプトは、必要になってからで構いません。使ってもいない仕組みを先に入れると、使われないまま残ります。

## 中身

| ディレクトリ | 中身 |
|---|---|
| [`prompts/`](prompts/) | 貼るだけのプロンプト7本。いつ貼るかの対応表つき |
| [`examples/`](examples/) | 弊社が実際に使っているファイル（サブエージェント・記憶・スキル2本） |
| [`reference/`](reference/) | 出来上がりの答え合わせ用。ルールファイルの骨格、記憶の書き方、フックの動く実装 |

`reference/` は、プロンプトが作ったものと見比べるために置いてあります。先に読む必要はありません。

## 足していく順番

前が後ろの土台になります。上から順に、**困ってから**足してください。

1. **ルールのファイルと記憶** — `prompts/01`。毎回説明していることを1枚に。前提の説明が要らなくなる
2. **止まる条件と、完了の証拠** — `prompts/02` `prompts/03`。勝手に進む・できていないのに完了する、を減らす
3. **分業** — `prompts/04`。調べ物を読み取り専用の別エージェントへ。本題が押し流されなくなる
4. **機械で止める** — `prompts/05`。取り返しのつかない操作を実行の直前で拒否する
5. **手順のファイル化と自動起動** — `prompts/06` `prompts/07`。3回やった作業を手順にする。読ませ忘れが減る

1だけなら半日で形になります。

## 使うときの注意

- フックのスクリプトは、**絶対パスで登録し、実行権限を付けてください**。どちらかを忘れると無言で動きません
- [`prompts/05-block-outbound-hook.md`](prompts/05-block-outbound-hook.md) のフックは最後の砦であって、判断の代わりではありません。塞いでいないパターンは必ず残るので、ルールファイル側の記述は緩めないでください
- 取り消せない操作は、フックで止めるより、**そもそも実行できない作りにする**ほうが強い方法です。送信の指定を渡すとエラーになるコードにする、追記以外の書き込み方法を持たせない、といった形です

Claude Code を想定していますが、考え方は他のエージェントでも同じです。パスの表記だけ読み替えてください。

業務システムからAIエージェントまで、低コスト・短納期でAI開発を手がけています。

この土台は、社内6人がそれぞれ組んだ運用を突き合わせて、共通していた部分を抜き出したものです。元になった事例集は「当社でのAIエージェント運用方法」として公開しています。
