# ai-agent-ops-starter

AIエージェントを毎日の業務に載せるための土台です。Claude Codeのプラグインとして配布しています。

**このリポジトリは非公開です。**ホワイトペーパー「社内でのAIエージェント運用方法」の別冊をお渡しした方だけに招待しています。社内での複製と改変は自由です（MIT）が、社外への再配布はご遠慮ください。

AIに仕事を頼むたびに、会社のこと、担当のこと、やってはいけないことを説明し直していませんか。説明した内容は、そのウィンドウを閉じた時点で消えます。翌日はまた一からです。

この繰り返しから抜ける土台は、手で書く必要がありません。

## 入れる

```
/plugin marketplace add https://github.com/NoCode-Solutions/ai-agent-ops-starter.git
/plugin install ai-agent-ops@nocode-solutions
```

**この2行は、ターミナルではなくClaude Codeの対話画面に打ちます。**

1行目で止まる場合は、GitHubの認証が通っていません。非公開のリポジトリなので、先に `gh auth login` を済ませてから実行してください。

入れ終わったらClaude Codeをいったん終了して、もう一度起動してください。

立ち上げ直したら、作業に使うフォルダで次を実行します。gitのリポジトリでなくても構いません。

```
/ai-ops-setup
```

一覧に出てこないときは `/ai-agent-ops:ai-ops-setup` と打ってください。こちらが正式な名前で、ほかに同じ名前がなければ短いほうでも呼べます。

5つの質問が1問ずつ来ます。答えると `CLAUDE.md` と記憶の置き場ができます。所要は10分ほどです。

## 入るものと、聞かれるもの

**共通のものは入り、自社の中身だけが質問されます。**この境目がこのプラグインの設計です。

| | 中身 |
|---|---|
| インストールで入る（雛形） | 探索専用のサブエージェント `scout`、フックの実装2本、完了前に通す項目、ルールファイルの骨格 |
| `/ai-ops-setup` で作られる | `CLAUDE.md`、記憶（`memory/`）、記憶を読み込ませる結線 |
| `/ai-ops-add` で有効になる | フックの登録と、フックが塞ぐ対象 |

下の3つは、どこの会社でも同じにはなりません。`CLAUDE.md` に書くのはあなたの会社の事業であり、あなたが繰り返している説明であり、あなたの環境で取り返しがつかない操作です。ファイルでは運べないので、聞き出してから書きます。

とくにフックは、こちらが塞いでいる対象をそのまま有効にすると、**守られている気がするだけの状態**になります。インストールしても自動では登録しません。

## 足していく

土台ができたあとは、症状が出てから1つずつです。`/ai-ops-add` を実行するか、下の言葉で頼んでください。

| 症状 | 足すもの |
|---|---|
| 指示していないのに勝手に進んだ | 止まって確認する条件 |
| 「できました」が当てにならない | 完了前のチェックリスト |
| 調べ物をさせると本題が押し流される | 探索の分業（`scout` を呼ぶ） |
| ルールに書いたのに危ない操作をやろうとする | 実行の直前に仕組みで止めるフック |
| 同じ手順を3回以上説明している | スキル |
| 毎朝、状況を説明し直している | 現在地の自動読み込み |

先回りで全部入れないでください。使ってもいない仕組みは、使われないまま残ります。

## 中身

| ディレクトリ | 中身 |
|---|---|
| [`plugins/ai-agent-ops/`](plugins/ai-agent-ops/) | プラグイン本体。スキル2本・`scout`・フック2本・答え合わせ用の3点 |
| [`examples/`](examples/) | 社内で実際に使っているファイル。読むためのもので、インストールしても入りません |
| [`prompts/`](prompts/) | 予備。プラグインが使えない環境向けに、同じ内容を貼り付けでやる道 |

## 使うときの注意

- フックのスクリプトは、**絶対パスで登録し、実行権限を付けてください**。どちらかを忘れると無言で動きません。エラーも出ないので、効いていると思い込んだまま使い続けることになります
- フックは最後の砦であって、判断の代わりではありません。塞いでいないパターンは必ず残るので、`CLAUDE.md` の記述は緩めないでください
- フックで止まるのはシェル経由の操作だけです。ファイル編集ツール、MCP経由の操作、ブラウザ操作、別のシェルは止まりません。**「全部塞いだ」ではなく「設定した経路を塞いだ」**と考えてください
- 動作確認には本物の危険なコマンドを使わないでください。必ず拒否する合言葉を1つ仕込み、それを含む無害なコマンドで試します
- 取り消せない操作は、フックで止めるより、**そもそも実行できない作りにする**ほうが強い方法です。送信の指定を渡すとエラーになるコードにする、追記以外の書き込み方法を持たせない、といった形です

Claude Code 以外のエージェントでも、考え方は同じです。その場合は [`prompts/`](prompts/) を使ってください。

## 作った会社

株式会社ノーコードソリューションズ（[nocode-sol.co.jp](https://nocode-sol.co.jp/)）
業務システムからAIエージェントまで、低コスト・短納期でAI開発を手がけています。

この土台は、社内6人がそれぞれ組んだ運用を突き合わせて、共通していた部分を抜き出したものです。元になった事例集は「社内でのAIエージェント運用方法」として公開しています。
